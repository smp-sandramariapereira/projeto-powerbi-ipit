- [ ] Valores conferidos contra uma tabela/matriz de verificação.
- [ ] Mudança de filtro altera medidas de modo esperado.
- [ ] Pelo menos três testes registrados.
- [ ] Resultado interpretado sem afirmar causalidade não demonstrada.
- [ ] Um usuário consegue utilizar a tela com mínima explicação.
